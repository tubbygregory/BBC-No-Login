# What's new

## 1.1.0

- Redesigned the extension popup with a clear saved-preference status, a switch, dark mode, and keyboard-friendly controls.
- Added confirmation after choosing **Never**, with an **Undo** action.
- Made loading, saving, and error states clear, with a retry option when a choice cannot be read or saved.
- Added a guided setup page in the download, with instructions for Chrome, Edge, and Brave.
- Added illustrated installation help and a smaller release ZIP containing the extension and its setup guide.

Existing preferences are preserved when you update the files in the same installation folder and reload the extension.

## 1.0.0

- Added **Never** beside supported optional BBC sign-in reminders.
- Remembered the choice across BBC domains in the same browser profile.
- Added a popup to enable the preference or allow reminders again.
